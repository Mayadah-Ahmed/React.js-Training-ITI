# React.js Training – ITI

A collection of selected projects and tasks I completed during my **React.js training at the Information Technology Institute (ITI)**.

This repository showcases my hands-on practice with React fundamentals, state management, API integration, forms, interactive UI development, and Generative AI integration.

## 🚀 Projects

### 📝 Todo List

A Todo List application built with React to practice managing application state and implementing common CRUD operations.

**Key concepts:**

- React Components
- `useState`
- Adding, editing, and deleting todos
- Marking todos as completed
- Conditional rendering

---

### 🛍️ Product Management

A product management application integrated with the **Fake Store API** to practice working with external APIs and managing application data.

**Technologies:**

- React.js
- Axios
- Zustand
- Formik
- Yup
- Bootstrap

**Key features:**

- Fetching products from an external API
- Product management
- Form handling and validation
- State management
- Responsive UI

---

### 🔄 Sorting Algorithms Visualizer

An interactive React application that visualizes sorting algorithms through animated steps, making the sorting process easier to understand.

**Key concepts:**

- Sorting algorithms
- Interactive data visualization
- Animations and dynamic UI updates

---

### 🤖 AI Chatbot

A React-based chatbot that integrates Generative AI to provide an interactive conversational experience.

**Key concepts:**

- React components and state
- API integration
- Generative AI
- Asynchronous JavaScript
- Interactive UI
